# CRE 26 Tokyo - Conference Website

## Project Overview
Website for "Current Research in Egyptology 26" (CRE 26) International Conference held at the University of Tsukuba, Tokyo Campus. The site features a modern, "Digital Egyptology" aesthetic with high-contrast cyber-modern design.

## Recent Updates (2025-12-30)
- **Multilingual Support**: Added English, Japanese, and Arabic language switching.
- **RTL Support**: Full Right-to-Left layout support for Arabic version.
- **Content Updates**: Updated Call for Papers with new topics, timeline, and email address.
- **Neon Gimmicks**: Implemented "Running Neon Border" effect on cards, animated gradients on menus and scrollbars.
- **High Contrast**: Optimized text visibility with solid white backgrounds and darker image overlays.
- **Menu Redesign**: Pill-shaped menu items with animated gradient backgrounds.

## Key Features
- **Responsive Design**: Fully responsive layout that works on mobile, tablet, and desktop.
- **Glassmorphism UI**: High-end frosted glass effects using `backdrop-filter`.
- **Interactive Elements**: Smooth scrolling, mobile menu, accordion sections, and dynamic navigation highlighting.
- **Dynamic Backgrounds**: Slideshow for Home, static thematic backgrounds for subpages.
- **Internationalization**: Client-side language switching (EN/JP/AR) with persistent preference storage.

## File Structure
- `index.html`: Main landing page
- `css/style.css`: Main stylesheet
- `css/i18n.css`: Language specific styles and font definitions
- `js/main.js`: Core functionality and language logic
- `js/translations.js`: Dictionary for multilingual text
- `images/`: Asset directory including logos and background images.
